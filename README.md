# Por Um Fio

App de mesa para a campanha de Tormenta20.

## MVP da sessão
- Fichas de Hippion, Malekir, Neo, Fani e Zuri
- PV e PM com controles rápidos
- Ataques e rolagens de d20
- Poderes
- Inventário
- Perícias com rolagem
- Salvamento local no navegador

## Importante
Esta versão é o modo de emergência para a sessão: cada aparelho salva seu próprio estado em localStorage. A arquitetura está separada para que uma camada de banco em tempo real possa ser adicionada depois.
